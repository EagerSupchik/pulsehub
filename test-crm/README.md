# PulseHub Test CRM

Автономная тестовая CRM на Node.js без сторонних зависимостей.

Из корня PulseHub запустите:

```powershell
npm run test-crm
```

Откройте `http://localhost:4100`. CRM работает автономно и ничего не знает о PulseHub.

Внешние пользователи:

- `test-crm-user-1` — Анна Смирнова;
- `test-crm-user-2` — Иван Петров.

В PulseHub создайте CRM-подключение с типом `test-crm` и адресом `http://localhost:4100`, затем сопоставьте внешний ID с учётной записью сотрудника. PulseHub самостоятельно запрашивает `GET /api/tasks` только при загрузке раздела задач или ручном обновлении.

Данные задач сохраняются в `data.json`. Тестовая CRM не хранит адрес PulseHub, Integration ID или секрет синхронизации и никогда не выполняет исходящие запросы в платформу.
